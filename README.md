## 5x 到底指什么：不是性能倍数，是额度定位

官方目前对两档 Pro 的说明是：核心能力相同，主要差别在使用额度。100 美元档相对 Plus 大约是 5 倍用量，200 美元档大约是 20 倍。这就是「5x」「20x」这两个说法的来源。

有几个细节，第三方商品页基本不会主动强调：

- 5x 不等于回答质量是 Plus 的五倍，也不代表速度固定快几倍。两档 Pro 共享同一组核心能力，包括 Pro 模型、Codex、Deep Research、图片生成、Memory 和文件上传。
- 部分模型有独立额度，某一项用完后会暂时不可用，等重置时间到点才恢复，期间其他模型照常能用。
- 页面上的 Unlimited 同样受合理使用和防滥用规则约束，不能理解成允许自动抓取、账号共享、转售或无限并发。

## 下单流程：账号要交出什么

公开教程里的操作大致是这样：

1. 用手机号或邮箱注册，邀请码在注册时填写，用来挂钩折扣。
2. 选择商品和订阅时长（月付 / 季付 / 年付）。
3. 确认要开通的 ChatGPT 账号，可以是已有账号，也可以让平台代注册。
4. 按提示获取并上传该账号的登录状态信息（Session，通常是 JSON 格式）。
5. 核对账号邮箱，生成支付二维码，微信扫码付款。
6. 等待开通。有教程称系统一般 2 小时内完成，实际往往会更快。

第 4 步是整件事里最该想清楚的一环。

上传 Session，等于把这台账号的登录状态交给第三方，平台据此自动登录并处理订阅。平台的说法是为了完成订阅和后续续订。从结果看，它确实让「账号是你的、订阅挂在你的号上」这件事成立；但从权限看，这不是纯支付行为。你付出的不只是 105.99 美元，还有一份登录凭证。

另外，2026 年 8 月有用户收到过平台提示，之前的 Plus 订阅可能失效，需要重新上传当前有效的 Session 才能继续处理剩余月份的续订。也就是说，这个凭证不是上传一次就永远不用管。

## 5x 还是 20x

判断标准只有一个，不用想太复杂：

- **Plus 的额度经常不够用，但还没到全天重负载** —— 5x 是合理的起点，用一半的月费拿到同一组 Pro 核心能力。
- **5x 的额度已经频繁打断你的工作** —— 当等待重置的成本明显高于每月多付的 100 美元，才轮到 20x。
- **只是偶尔跑高级任务** —— 继续用 Plus，多出来的钱花在这儿不划算。

需要提醒的是，5x 并不能真正消除额度瓶颈，它只是把触顶的时间往后推。如果你的工作节奏本来就在反复撞墙，选 5x 之后大概率还会想升 20x。

## 哪些人适合走第三方，哪些人别碰

适合：

- 账户在支持地区、但支付方式一直过不去，且愿意把登录状态授权出去的人
- 原有 WildCard 余额还在平台里、想顺手用掉的用户
- 愿意先买最短周期试水，能接受中间可能出一次故障的人

不适合：

- 手里有稳定可用的海外信用卡、官方结账一路顺畅的人——直接官方订阅更干净
- 把这笔钱当成「必须零故障」的生产环境投入的人
- 账号里有重要历史对话、不愿意让任何第三方接触登录凭证的人
- 只想找最低价的人。第三方服务从来不是最低价方案，便宜的那条路是成品号，风险等级完全不同。
